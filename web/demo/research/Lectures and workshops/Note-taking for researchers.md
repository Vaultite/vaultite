# Workshop: note-taking for researchers

Graduate school skills programme. Three hours, 2026-12-03, Library seminar room 2. Up to 20 doctoral students from any discipline.

## Aims

By the end, participants should be able to:

- Explain why rewriting a source in their own words helps more than copying it [@mueller2014; @ahrens2017]
- Set up literature notes linked to a reference manager, with citekeys
- Use retrieval, not rereading, to keep what they read [@roediger2006]
- Decide how much structure their own system needs, without building one that costs more than it gives [@sweller1988]

## Plan

| Time | Activity |
| --- | --- |
| 0:00 | Introductions: what does your current system look like? Draw it. |
| 0:15 | Short history: commonplace books, card indexes, the memex [@blair2010; @bush1945] |
| 0:35 | Luhmann's rules, with a printed set of cards to sort [@luhmann1981] |
| 1:05 | Break |
| 1:15 | Hands-on: one article, three literature notes, linked to each other and to a citekey |
| 2:00 | Retrieval drill: find a note from last week without search |
| 2:30 | Discussion: when is a note system worth it? Notes as infrastructure [@star1999] |
| 2:50 | Wrap up and handout |

## Materials

- Printed card sets (40 cards, numbered in Luhmann's branching style)
- A sample BibTeX library and a short guide to Pandoc citations
- Handout with the reading list below

## Reading list for participants

- [@ahrens2017], chapters 1 to 3
- [@luhmann1981] in translation, if the library copy is available
- [@clark1998], for anyone who wants the philosophy
