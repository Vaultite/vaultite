## Guides: the user's notes on their apps and sites
One note per app or site, in `Guides/`: how it works, where things are, how they use it. A summoned ask there (its Talk
key, on screen or in a web tab of the app) carries its guide, cut past 1500 characters.
```yaml
type: guide
app: [com.figma.Desktop]   # bundle ids (the app's)
site: figma.com            # or domains, subdomains too (a site's guide wins in a browser)
```
The body is theirs to read and edit: short sections, what's where and their habits ("I name layers in kebab-case"). Add
to one rather than start another; write one only when they say yes.
